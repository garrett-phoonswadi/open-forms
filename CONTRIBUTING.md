# Contributing

Thanks for helping out!

1. Fork and create a branch.
2. Follow WordPress coding standards; sanitize input, escape output, verify nonces/capabilities.
3. Run `php -l open-forms.php` and `php tests/run.php`; add tests for new behavior. Run `node tests/e2e.mjs` for changes to forms, uploads or submission.
4. Open a pull request describing the change.

By contributing you agree your work is licensed under GPL-2.0-or-later.
